§1. Натуральные числа — проверка (стр. 6–11)

Проверь себя сам

Впиши ответ на месте черты. Когда закончишь все 5 — переверни лист вверх ногами и прочитай ответы внизу страницы, чтобы проверить себя.

  1. 5307 = 5·1000 + ·100 + 0·10 + 7
  2. Наименьшее натуральное число — это
  3. не является натуральным числом
  4. В числе 4750 три разряда после тысяч: сотни, десятки и
  5. Число 4750 оканчивается на 0, значит оно (чётное/нечётное)

Ответы (переверни лист):

1) 3    2) 1    3) 0    4) единицы    5) чётное

Вопросы, которые может задать мама (устно)

Не показывай ребёнку эту часть — просто зачитай вопросы вслух и сверься с ответом в скобках.

  1. Что такое натуральное число? (число для счёта предметов: 1,2,3,4…; ноль не входит)
  2. Есть ли у натурального ряда самое большое число? (нет, а самое маленькое — 1)
  3. Как называется группа из трёх разрядов — единицы, десятки, сотни? (класс единиц)
  4. Разложи число 5307 по разрядам. (5·1000 + 3·100 + 0·10 + 7)
  5. Число 128 — чётное или нечётное? Почему? (чётное, оканчивается на 8)
  6. Назови три нечётных однозначных числа. (любые три из: 1, 3, 5, 7, 9)
