§5. Числовые и буквенные выражения. Упрощение выражений

Упростить — значит записать короче: собрать одинаковые буквы и посчитать числа.

📖 — пример из учебника✏️ — пример придуман для этого листа, в учебнике его нет⚠ — где чаще всего ошибаются

1Вынести общий множитель за скобки

a·x + b·x = (a + b)·x    a·x − b·x = (a − b)·x

Буквы: x — общий множитель (буква или число), он есть в каждом слагаемом.

📖 из учебника, стр. 27
  1. 13k + 7k = (13 + 7)k = 20k
  2. 128·67 − 28·67 = (128 − 28)·67 = 100·67 = 6700
✏️ мой пример
  1. 23y − 8y + 5y = (23 − 8 + 5)y = 20y
  2. 37·14 + 63·14 = (37 + 63)·14 = 1400

⚠ Частая ошибка: складывать буквы с числами: 19c + 28 — это уже ответ, а не 47c. Собирать можно только одинаковые буквы.

2Раскрыть скобки, если перед ними «+»

a + (b + c) = a + b + c — скобки просто убираем
📖 из учебника, стр. 26

8y + (3y + 6) + (y + 1)

  1. = 8y + 3y + 6 + y + 1
  2. = (8 + 3 + 1)y + (6 + 1)
  3. = 12y + 7

⚠ Частая ошибка: потерять одиночную букву: y — это 1·y. Если её не посчитать, получится 11y вместо 12y.

3Рациональный способ: переставить и сгруппировать

сочетательное: 4·(25·789) = (4·25)·789   распределительное: (500 + 25)·4 = 500·4 + 25·4

Когда применять: в лоб считать долго, а после перестановки получается круглое число.

📖 из учебника, стр. 27
  1. (500 + 25)·4 = 2000 + 100 = 2100
  2. 5a·(7·4) = 4·5·7·a = 140a
  3. 14c + 18 + 5c + 10 = (14c + 5c) + (18 + 10) = 19c + 28
