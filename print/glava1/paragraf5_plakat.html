§5. Упрощение выражений

Два фокуса, которые превращают длинное выражение в короткое: выносим общий множитель и раскрываем скобки.

Вынесение общего множителя за скобки

Пример из учебника:

44x + 16x = (44+16)·x = 60x

Общий множитель — x, он есть у обоих слагаемых.

Раскрытие скобок

Если перед скобкой «+» — просто убираем скобки:

8y + (3y+6) + (y+1) = 8y + 3y+6 + y+1

Термины

общий множитель

Множитель, одинаковый у всех слагаемых суммы.

рациональный способ

Способ вычисления, который делает счёт легче.
