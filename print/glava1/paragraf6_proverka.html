§6. Уравнения — проверка (стр. 31–34)

Проверь себя сам

Впиши ответ на месте черты, потом переверни лист и проверь себя.

  1. Неизвестное слагаемое = сумма −
  2. Неизвестное уменьшаемое = разность +
  3. Неизвестное вычитаемое = уменьшаемое −
  4. Неизвестный множитель = произведение :
  5. Неизвестный делитель = делимое :

Ответы (переверни лист):

1) известное слагаемое    2) вычитаемое    3) разность    4) известный множитель    5) частное

Вопросы, которые может задать мама (устно)

Зачитай вопросы вслух, сверься с ответом в скобках.

  1. Что такое корень уравнения? (число, при котором получается верное равенство)
  2. Реши: x + 18 = 26 + 15. (x=23: сначала 26+15=41, потом x=41−18=23)
  3. Может ли у уравнения не быть ни одного корня? (да, например x·0=15)
  4. Как найти неизвестный делитель? (делимое разделить на частное)
