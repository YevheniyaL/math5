§7. Формулы. Вычисления по формулам

Три формулы, которые встретятся в математике ещё много раз — запомни их вместе с диаграммой, а не только буквами.

Три главные формулы

периметр треугольника

P = a+b+c

площадь прямоугольника

S = a·b

a=S:b  b=S:a

путь, скорость, время

s = v·t

v=s:t  t=s:v

Движение по реке

по течению
v(теч.) = v(собств.) + v(реки)
против течения
v(теч.) = v(собств.) − v(реки)
