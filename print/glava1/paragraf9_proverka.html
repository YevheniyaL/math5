§9. Последовательность из натуральных чисел — проверка (стр. 46–49)

Проверь себя сам

Впиши ответ на месте черты, потом переверни лист и проверь себя.

  1. 1, 4, 9, 16, 25 — это последовательность чисел
  2. 1, 8, 27, 64, 125 — это последовательность чисел
  3. В последовательности Фибоначчи каждое число равно сумме предыдущих
  4. 4, 8, 12, 16, 20 — числа, которые делятся на

Ответы (переверни лист):

1) квадратов    2) кубов    3) двух    4) 4

Вопросы, которые может задать мама (устно)

Зачитай вопросы вслух, сверься с ответом в скобках.

  1. Что нужно найти, чтобы продолжить последовательность? (закономерность — правило, по которому она составлена)
  2. Продолжи: 1, 4, 9, 16, 25, … (36 — следующий квадрат, 6²)
  3. Продолжи: 1, 1, 2, 3, 5, 8, … (13 — сумма двух предыдущих: 5+8)
  4. Как называется закономерность, где каждое число — куб натурального числа? (последовательность кубов)
