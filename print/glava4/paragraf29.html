Дуплекс-печать: печать на двух сторонах, переплёт по длинному краю. Получится 3 двусторонних карточки.

Односторонний принтер: напечатайте лист 1, переверните стопку и напечатайте лист 2 поверх.

Лист 1 — правила (лицевая сторона)

дробь от числа
число по его дроби
как отличить задачи

Лист 2 — формулировки (обратная сторона, ячейки в каждом ряду зеркальны — для совпадения при печати)

Чтобы найти число по его дроби, нужно разделить число на эту дробь. Пример: 3 : 3/4 = 4.
Чтобы найти дробь от числа, нужно умножить число на эту дробь. Пример: 45 · 4/9 = 20.
«часть ОТ числа» → умножение. «дробь числа равна ...» → деление.
