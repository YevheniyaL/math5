§46. Решение текстовых задач — проверка (стр. 70–73)

Проверь себя сам

Впиши ответ на месте черты, потом переверни лист и проверь себя.

  1. В лагере отдыхали 15, на море 9, и там и там — 2. Всего учащихся: ___
  2. Формула: |A∪B| = |A| + |B| − ___
  3. Пересечение вычитают, чтобы не посчитать общие элементы ___
  4. Казахским владеют 40, английским 20, обоими — 15. Хотя бы одним языком: ___

Ответы (переверни лист):

1) 22    2) |A∩B|    3) дважды    4) 45

Вопросы, которые может задать мама (устно)

Зачитай вопросы вслух, сверься с ответом в скобках.

  1. Число элементов объединения равно сумме элементов множеств без вычитания пересечения. (неверно)
  2. Пересечение вычитают, чтобы не посчитать общие элементы дважды. (верно)
  3. 15 + 9 − 2 = 22 — пример из задачи про лагерь и море. (верно)
  4. Формула для объединения работает только для непересекающихся множеств. (неверно)
